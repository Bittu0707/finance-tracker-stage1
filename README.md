# 💸 Personal Finance Tracker - Stage 1

A simple React + Vite web app for tracking personal transactions and viewing monthly expense charts.

## 🧱 Tech Stack
- React + Vite
- Express + MongoDB
- Tailwind CSS
- Recharts

## 🚀 Features
- Add, Edit, Delete transactions
- Monthly expenses bar chart
- Basic form validation
- Responsive UI
